# Maniac 2B-0 — проверка 25.10.2026

Ветка сайта `test`. На старте уже были локальные изменения скачивания, иконок и
документации. Они сохранены: первичная загрузка Maniac 1.2 остаётся Google Drive,
зеркало — Яндекс Диск, обе пары кнопок сохраняют иконки и открытие внешних ссылок.
Рабочее дерево не сбрасывалось; коммит, push, слияние и деплой не выполнялись.

## Что выполнено

- Единые типы и реестры 11 игровых сущностей с ID и типизированными отношениями.
- Отдельные исторические снимки и снимок проверенных исходников; независимый
  редакторский текст изменений, before/after для добавления/изменения/удаления.
- Общие compact/detail карточки персонажей, способностей, перков и предметов,
  EntityLink без ссылок на неопубликованные статьи и компонент для хроник.
- Инвентаризация 410 ресурсов удалённого commit, выборочный импорт 7 ресурсов,
  происхождение и хеши. Оптимизированы только две крупные иллюстрационные иконки.
- GLB Хранителя из оригинальных геометрии и текстуры: 22 кости, 84 куба,
  18 плоских деталей, 848 треугольников. Одна модель, без альтернативных форм.
- Изолированный рабочий 3D-прототип с управлением камерой, lazy-load и fallback.

Основное описание: [MANIAC_WIKI_FOUNDATION.md](MANIAC_WIKI_FOUNDATION.md).
Инвентаризация: `MANIAC_ASSETS.md` и `maniac-assets-inventory.json`.

Изначальные ошибки TypeScript в обобщённой типизации снимков/валидатора устранены.
Проверка размера WebP уточнена по спецификации lossless VP8L: core ImageUtils
не читает этот формат без дополнительного обработчика.
Существующее предупреждение React Router о `use client` остаётся.
Preview-сборка дополнительно предупреждает о viewer chunk >500 КБ: он имеет
около 643 КБ minified / 163 КБ gzip, загружается только по запросу и не попадает
в публичную сборку. GLB — 104 768 байт. Компрессионные runtime-декодеры не добавлены.

В автоматических проверках есть негативные случаи: дубли ID, битая связь,
неподтверждённый after-снимок. Проверяются три вида изменений, отсутствие
автоматической подстановки текущего баланса в старую хронику, local asset hashes,
реальные размеры изображений, кости/индексы/UV GLB и исходная PNG-текстура.
Перезарядка 60 с из кода не появляется в карточке хроники 1.2.
Проверяется отсутствие GLB/GLTFLoader/WebGLRenderer в публичных ассетах и bundle.

## Браузер

Microsoft Edge, готовая preview-сборка `http://127.0.0.1:4175/maniac-lab.html`.
Проверены desktop 1440×1000 и mobile viewport 390×1000 с touch emulation.

- Модель видна с оригинальной текстурой; UV/геометрия просмотрены по скриншотам.
- До нажатия «Загрузить 3D-модель» нет запросов GLB или ModelCanvas chunk.
- Мышь вращает модель; колесо и кнопки меняют масштаб.
- Касание вращает камеру; двухпальцевый pinch меняет масштаб.
- Кнопки доступны с клавиатуры, Enter выполняет приближение.
- Сброс возвращает прежний вид. Пиксели внутренней области canvas после сброса
  совпадают; одна строка внешней рамки исключена из-за субпиксельной позиции
  скриншота после прокрутки. Первоначальное сравнение целых PNG было уточнено.
- В покое число вызовов RAF не растёт; это также проверено с reduced motion.
- После выгрузки canvas удалён, старый WebGL-контекст isContextLost=true.
  Повторная загрузка viewer работает без ошибок JS.
- При принудительном отсутствии WebGL показан fallback, пустой canvas отсутствует.
- Изображения загружены, горизонтального переполнения нет, внешних сетевых запросов
  при просмотре прототипа нет. EntityLink не создаёт фиктивные адреса Wiki.
- Главная публичного сайта не запрашивает движок/GLB. Публичные lab и Wiki URL
  возвращают 404; количество маршрутов остаётся прежним.

В ходе проверки локальный публичный preview был остановлен; после запуска 4173
финальная проверка изоляции прошла. Реальные мобильные устройства, Safari и Firefox
не проверялись. Игра в Minecraft и точное совпадение игрового освещения не проверялись.

## Скриншоты и ограничения

Артефакты чата, папка `maniac-foundation`:

- `keeper-1440.png`, `keeper-390.png` — модель крупным планом.
- `prototype-1440.png`, `prototype-390.png` — прототип целиком.
- `fallback.png` — режим без WebGL.
- `browser-results.json` — результаты сценариев.

Анимации пока не воспроизводятся: сохранены исходники idle/Walk/swim/attack, но
прототип показывает статическую позу. Следующий технический шаг — проверенная
конвертация анимационных каналов; незаметная имитация GeckoLib не добавлялась.
Реестры и индексы версий частичные; 1.0/1.1 не наполнены. Wiki-навигация, поиск,
полные статьи и полный перенос хроник остаются дальнейшими этапами.
Для будущего наполнения нужно разрешить разночтения кода и исторических описаний
и подтвердить соответствие исходников конкретным публичным версиям.
