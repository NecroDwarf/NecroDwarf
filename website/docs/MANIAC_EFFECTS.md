По просьбе пользователя «Слабое исцеление» исключено из каталога и меню через
`wiki/published-effects.ts`; полный аудит исходников сохраняет все регистрации.
Описания написаны для игроков: короткое действие, величина и время без деталей
реализации. Формат: «+1 HP / 12 сек.», «+2 маны / сек. за уровень».
HP, мана, урон, скорость и уровень отображаются едиными SVG-иконками GameGlyph;
подсказки доступны при наведении и фокусе, названия — экранным дикторам.
Текст и типизированные вставки хранятся совместно, без HTML в данных.

Длительность
не считается постоянной характеристикой регистрации: числа приведены только
для подтверждённых источников применения. Например, эффект крика длится секунду,
но маркер — пять; «Кредит» постепенно лечит половину максимального здоровья,
затем наносит отложенный урон в 1,15 раза больше лечения; Чума сама не наносит
периодический урон. Комментарии не заменяют исполняемый код.

Оригинальные PNG скопированы без изменения в `assets/wiki/effects`. Для
`weak_instant_health` отдельной текстуры в снимке нет; эффект не публикуется.
Сведения об исходниках, местах использования и SHA-256
находятся в `wiki/data/effect-sources.json`. Описания — в
`wiki/data/effect-descriptions.ts`; лёгкие метаданные для меню — в
`wiki/effect-route-metadata.ts`. Полный контент и иконки загружаются страницей
эффектов, а не общим хедером. Новый EntityKind не вводился: раздел является
самодостаточным справочником с устойчивыми якорями эффектов.

Повторный импорт из локального игрового репозитория (только чтение):

```powershell
cd website
node scripts/prepare-maniac-effects.mjs E:/coding/Github/Maniac-mod-evolution
```

Скрипт читает только закреплённый commit, не меняет файлы игрового репозитория
и не записывает настройки Git. После импорта нужно проверить типы и описания:
новые регистрации не получают выдуманный текст автоматически.

Проверки: `npm run build`, `npm run check:catalogs`, `npm run check:effects`,
`npm run check:loading`, `npm run format:check`. `check:effects` проверяет
полноту HTML, отсутствие дублей, исходники и использования каждой регистрации,
хеши иконок и ссылки каскадного меню. Публикация и домен не менялись.

Итог: `npm run build` (включая typecheck), полный `npm run check` и
`npm run format:check` прошли; статически сформированы 190 страниц и 404.
Прежний бюджет загрузки сохранён без ослабления проверок: вложенное меню
загружается при раскрытии, список разделов используется совместно маршрутами
и панелью Wiki. В браузере проверены группы механик, фильтры эффектов,
пустой результат, сброс и вложенная навигация с клавиатуры.
