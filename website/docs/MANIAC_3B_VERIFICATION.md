# Maniac Wiki 3B — перки и способности

Проверено 28.10.2026 в ветке `test`. Production-деплой и слияние не выполнялись.

## Объём и источники

Источник — [закреплённый commit мода](https://github.com/doflare123/Maniac-mod-evolution/tree/8692f66dc76582144be85d553d43a41f189b64e7).
`PerkRegistry.java` регистрирует ровно 44 уникальных игровых ID: 19 SURVIVOR,
15 MANIAC, 10 ALL. Типы по Builder: 17 PASSIVE, 11 ACTIVE, 10 PASSIVE_COOLDOWN,
5 HYBRID, 1 CHARGED. Каталог учитывает все пять типов и реальные фазы.
Расположение Java-класса в папке не определяет игровую сторону.

Созданы два каталога, 44 статьи перков и 12 статей способностей: всего 58 новых
маршрутов, 86 страниц сайта. Публикация сущностей: 15 персонажей + 44 перка +
12 способностей. Предметы, механики и карты отдельно не опубликованы.
15 Flower-перков дополнены в существующих сущностях без дубликатов.

Для способностей проверены 11 записей этапа 3A. Дополнительно опубликована
«И куда собрался?» Мясника: `HookItem implements IItemWithAbility`, зарегистрированный
предмет, собственные обработчики и оригинальная иконка. Пассивный «Взгляд бездны»,
действия предметов и действия экипировки явно различаются. Произвольные
`addFeature()` и эффекты перков не превращены в новые способности.

Машинные аудиты содержат пути классов, аргументы локализации, вычисленные значения
и замечания: [перки](maniac-3b-perk-audit.json), [способности](maniac-3b-ability-audit.json).
`wiki/data/provenance.json` фиксирует SHA-256 исходников. Подготовка сверяет байты
с Git blob SHA из дерева pinned commit. Исходный репозиторий не изменялся.

## Разрешённые расхождения

| Сущность            | Расхождение                                                        | Опубликованное значение                                                                                       |
| ------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Мимик               | Аргументы радиуса и длительности переставлены в `getDescription()` | Радиус 2 блока, действие 5 с по обработчику                                                                   |
| Быстрая реакция     | Миллисекунды передаются в шаблон с подписью секунд                 | 450 мс = 0,45 с                                                                                               |
| Золотая медаль ГТО  | Комментарий называет 80 с, Builder — 45 с                          | 45 с; рывок описан как импульс, без выдуманной постоянной дальности                                           |
| Путеводная Света    | Локализация говорит о случайной цели после взлома                  | Активация ведёт к ближайшему активному выжившему в том же мире на 2 с                                         |
| Телепортация Смерти | Getter — 30 с, серверный `TELEPORT_COOLDOWN` — 60 с                | 60 с, 7 маны, подготовка 113 тиков = 5,65 с                                                                   |
| Спасибо, доктор     | Краткое описание персонажа говорит о следующей атаке               | MedicalMask/MedicActiveAbility: 50% входящего урона союзнику в радиусе 4 блоков в течение 15 с; 30 маны, 60 с |

Отсутствие Builder mana/CD не превращено в ноль. Служебный cooldown 9999 у
одноразовых перков показан как «Один раз за матч». Динамические результаты
сохраняются в формулах и условиях. Для Reality Anchor отдельно показаны жизнь
заряда 60 с, максимум 2 заряда и лимит 2 за матч. Параметры действия не
приравниваются к стоимости активации.

## История и изображения

Все 21 существовавшая историческая revision сохраняют SHA-256 сериализованного
JSON: [контрольный снимок](maniac-3b-historical-sha256.json). Он создан до изменений;
проверка сравнивает текущие release-данные с этим снимком.
Совпадение всего баланса pinned commit и публичного ZIP 1.2 не заявляется.

44 оригинальных PNG сопоставлены с фактическим базовым `Perk.getIcon()`:
переопределений у зарегистрированных классов нет. Исторические 15 WebP сохранены
без замены; 29 новых подготовлены с alpha, удалением пустых полей и lossless WebP
до 256 px. Манифест `assets/wiki/perks/imports.json` хранит исходные и выходные
хеши, размеры и пути всех 44 изображений. Используется общий `EntityIcon`.
Для одержимости взята настоящая плоская `ghost_hand.png`, для крюка — `hook.png`.
Runtime-загрузок ресурсов из GitHub нет.

## Архитектура и загрузка

Новый контент использует общий реестр сущностей, `EntityLink`, `EntityStats`,
WikiLayout и существующий `routePage`. Каталоги получают короткие данные;
каждая статья импортирует свой JSON через отдельный entry. Граф зависимостей
и реальные запросы Edge подтверждают отсутствие других полных статей,
полных хроник, Three.js и GLB на этих маршрутах. Изображения статьи
запрашиваются только для её иконки. Небольшие ресурсы могут быть inline.

Общие лёгкие каталоги и реестр связей остаются разделяемыми модулями. Это не
обещание нулевой загрузки метаданных других сущностей. Начальный JS сайта не
содержит базы Wiki; все полные тексты 56 статей изолированы.

Полный HTML каждой статьи генерируется через прежний `renderToString` после
предзагрузки entry. Гидратация предварительно загружает тот же модуль. SPA
сохраняет документ при переходах. Новый runtime SSR, router или backend не добавлен.

## Проверки и воспроизведение

Успешно выполнены:

- `npm run typecheck`
- `npm run build` — 86 страниц + 404
- `npm run check` — ссылки/метаданные/SSG, 108 сущностей, 44 перка, 12 способностей,
  типы/фазы/иконки, сложные числовые случаи, 21 историческая revision,
  персонажи/хроники/скачивание, изоляция чанков
- `npm run format:check`
- `npm run build:maniac-preview`
- `npm run check:reference:browser` — production preview в Edge

Для браузерного аудита нужен Playwright и установленный Edge. Внешний модуль
можно указать абсолютным путём через `PLAYWRIGHT_MODULE`; папку снимков —
через `WIKI_SCREENSHOT_DIR`. Скрипт сам поднимает временный сервер production
build и закрывает браузер/сервер. Результат: [сетевые замеры и screenshots](MANIAC_3B_BROWSER.json).

Проверены все 58 новых URL с отключённым JS и после гидратации, отсутствие ошибок,
сохранение исходного DOM-заголовка, фильтры всех сторон/типов, поиск/пустое
состояние/сброс, фильтр персонажей способностей, клавиатурный SPA-переход и
Мясник → крюк → Мясник. Десять разных страниц проверены на 320/390/768/1440 px:
переполнения нет. Сохранены 14 полных desktop/mobile-скриншотов и их viewport-копии;
визуально просмотрены каталог, заряжаемый перк и способность Смерти.

Существующие предупреждения Vite: игнорируемая директива React Router `use client`
и размер изолированного 3D-чанка DEV Preview. Новые статьи этот чанк не загружают.
Без `SITE_URL` локальная сборка намеренно получает noindex без sitemap;
deployment-конфигурация не менялась.

Подготовка данных требует кэша исходников `.audit/maniac-source-8692f66/tree.json`
и закреплённых классов (тот же кэш этапа 3A). Из `website` запускается
`python scripts/prepare-maniac-perks.py --fetch` с Pillow; флаг разрешает
получить отсутствующие ресурсы и канонические байты. Затем нужен Prettier для
выходных TS/JSON, включая `assets/wiki/perks/imports.json`. Это инструмент
подготовки контента, не обязательный этап обычной сборки сайта.

Игровой матч в Minecraft не запускался. Аудит доказывает соответствие указанным
исходникам и работу сайта, а не поведение иных сборок мода. Полный каталог
предметов, механики, карты и финальная визуальная полировка оставлены на следующие этапы.
