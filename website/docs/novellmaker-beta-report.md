# NovellMaker — открытая бета 0.1.0-beta.1

Источник: [официальный релиз](https://github.com/doflare123/NovellMaker/releases/tag/v0.1.0-beta.1), опубликован 10 ноября 2026. Исходники документации и логотипа закреплены на `52b1d06149b668aa76d5ed995c0a92118eb63824`.

- Статус и описания обновлены на главной, в каталоге и на странице проекта.
- Официальный `docs/branding/novellmaker.svg` используется в карточках и шапке проекта. Хеш и источник находятся в `assets/branding-source.json`.
- Доступны прямые ссылки на опубликованные Windows Setup, portable ZIP и экспериментальный Linux tar.gz. Бинарные файлы на сайт не копировались и не запускались.
- Выпуск добавлен в единый реестр, общую ленту и раздел выпусков проекта; дата не выводится из номера версии.
- Синхронизированы все 22 документа релиза, примеры, API inventory, поиск и навигация. Добавлены импорт диалогов и совместимость. Удалённый upstream-отчёт `verification.md` исключён из публикации.
- В исходном теге отсутствуют `examples/dialogue-import/dialogue.csv` и `dialogue.json`, хотя документация на них ссылается. Оригиналы Markdown сохранены с проверкой хешей; на сайте названия этих файлов отображаются без битых ссылок. Два исходных предупреждения явно сохранены в API inventory; любые другие ошибки синхронизация отклоняет.

Обычная сборка работает без доступа к GitHub. Деплой не выполнялся.

Проверки: `npm run build`, `npm run check`, `npm run format:check` и `git diff --check` — PASS. Собраны 214 страниц и 404; сохранены 113 API и 251 блок кода. `npm run check:novellmaker:browser` — PASS: 24 страницы без JS, гидратация, поиск, клавиатура и ширины 320/390/768/1440; отдельные проверки трёх загрузок, SVG, карточек и общей ленты.
