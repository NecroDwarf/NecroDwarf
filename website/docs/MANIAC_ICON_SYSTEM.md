# Игровые обозначения Wiki — 28.10.2026

Сложность в каталоге, hero статей и CharacterCard отображается пятью SVG-звёздами.
Число заполненных звёзд берётся из прежнего проверенного значения; для скринридера
доступна подпись «Сложность: N из 5». Шрифтовые символы и внешние icon-font не нужны.

`GameGlyph` — общие кодовые SVG-пиктограммы. Характеристики в EntityCard сохраняют
текстовые названия/единицы, а рядом с числом получают клинок, сердце, защиту,
каплю маны, дальность, перезарядку или рассудок. Значки декоративные и не заменяют
доступный текст. Новые единицы Stat: `health`, `damage`, `armor`.

Чтобы показать реальные примеры HP/урона, по закреплённому source:8692f66 проверены:

- Душа предков: базовое лечение 2 HP и ещё 2 HP за каждого другого выжившего в
  режиме наблюдателя (`AncestorSoulItem.BASE_HEAL`, `BONUS_PER_SPECTATOR`).
- Коготь зверя: базовый урон 1 HP без зарядов (`BeastClawItem.BASE_DAMAGE`).
- Прыжок зверя: 2.5 HP урона, радиус 1.8 блока, 10 с перезарядки, 5 маны
  (`LEAP_LAND_DAMAGE`, `LEAP_LAND_RADIUS`, `LEAP_COOLDOWN_SECS`, `LEAP_MANA_COST`).

Подготовка данных проверяет эти константы. Числа относятся к закреплённым исходникам,
не объявлены балансом архива 1.2; исторические revisions не изменены. Остальным
предметам числовые значения не приписывались по догадке или старому Java-fallback.

## Изображения снаряжения

Приоритет отображения:

1. Существующая оригинальная иконка/проверенный рендер из `data.icon`.
2. Проверенная inventory-иконка из `equipment-assets.ts` для текущего source-снимка.
3. Нейтральная SVG-пиктограмма вида предмета, явно обозначенная как условный символ.

Пистолет, посох, монеты, крюк и остальные предметы без готового рендера теперь
имеют визуальные обозначения. Эти символы не выдаются за графику или модели игры.
Тексты и имена снаряжения остаются видимыми.

Добавлены 11 изображений (около 34 КБ суммарно):

- Семь иконок кожаной брони используют настоящие слои chestplate/overlay Minecraft
  1.20.1. Цвета сверены с `CharacterLoadoutPreview` каждого персонажа. Нагрудник
  служит знаком комплекта, а не заменой описания его состава/характеристик.
- Иконки железного меча для ножа Агента и зельеварки — из тех же оригинальных
  Minecraft-ресурсов; сопоставление подтверждено игровым preview.
- Призрачная рука и игрушечный нож используют оригинальные textures, только после
  проверки, что их модели плоские `item/generated`/`item/handheld`.

Для объёмных предметов атласы текстур не используются как изображения. Ранее
подготовленный открытый рендер Кошмарной зажигалки сохранён. Внешний вид неизвестной
модели не придумывается.

Происхождение, SHA-256, размеры, версия Minecraft, URL и SHA-1 официального client
архива, SHA закреплённого мода: `assets/wiki/equipment/imports.json`. Архив лежит
только в игнорируемом `.audit/equipment-icons`; в Git включаются маленькие PNG.
На сайте нет запросов к GitHub/Mojang и нового WebGL ради иконок.

Повторная подготовка из `website` (Python с Pillow, источник игры в audit-кеше):

```powershell
python scripts/prepare-maniac-equipment-icons.py
npx prettier --write src/app/projects/maniac/wiki/data/equipment-assets.ts src/app/projects/maniac/assets/wiki/equipment/imports.json
```

`check-maniac-icons.mjs` включён в `npm run check`: проверяет PNG-хеши/размеры,
визуальные элементы каждого предмета, значки HP/урона, подтверждённые числовые
значения и доступные звёзды в SSG. Браузерная проверка покрывает Agent/Shaman/Ursa/
Ghost/Keeper при 320/390/768/1440 px, каталог, отсутствие ошибок гидратации и
горизонтального переполнения. Скриншоты находятся в артефактах `wiki-icons`.

Изменены общие Wiki UI-компоненты, вывод сложности в каталоге/статьях, единицы Stat,
подготовка подтверждённых данных, изображения, тесты и документация. Полные тексты
хроник, скачивание и структура публичных маршрутов не изменены.
