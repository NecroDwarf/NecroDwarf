# FriendSheep — Product Showcase / Social Sky

Дата проверки: 4 ноября 2026. Ветка сайта: `test`.

## Изменения

- `/projects/friendsheep` заменена специализированной одностраничной презентацией: hero, идея, три шага, шесть категорий возможностей, иллюстрация интерфейса, статусный roadmap, технологии, происхождение проекта и заключительный блок.
- По уточнению владельца FriendSheep позиционируется как сервис для любых мероприятий: от встреч друзей до концертов, лекций и учебных занятий. Обновлены hero, сценарий организации и участия, возможности, примеры интерфейса, каталог и SEO. Это уточнение продуктовой области, а не добавление новых функций сервиса.
- Голубая тема Social Sky изолирована CSS Modules внутри FriendSheep. Обновлена его иллюстрация в общем каталоге. По отдельному согласованию также убраны служебные подписи и оговорки из Maniac, Wiki и хроник; общий хедер, футер и NovellMaker не изменены.
- SEO-описание берётся из существующего `meta.ts`. Маршрут, React Router, `routePage` и SSG сохранены. Якоря страницы используют `Link`: это предотвращает конфликт нативной hash-навигации с существующим восстановлением прокрутки при работе с клавиатуры.
- Добавлена команда `npm run check:friendsheep:browser`, включённая в конец существующего `check:browser`. Прежние проверки и их пороги сохранены. Зависимости не добавлялись.

## Внешние ссылки и ограничения

GitHub-репозиторий и файл roadmap подтверждены через GitHub connector. Внешние ссылки открываются с `noopener noreferrer`.

При первоначальной проверке `https://friendsheep.ru/` web-инструмент сообщил о недоступности, а прямой HTTPS-запрос вне sandbox завершился ошибкой установления SSL-соединения. По прямому уточнению пользователя ссылка добавлена независимо от текущей доступности: две кнопки «Перейти на сайт» в hero и заключительном блоке открывают этот адрес в новой вкладке. Переходы к исходному коду удалены; отдельная ссылка на roadmap сохранена.

Доступность публичного сервиса и статус выпуска платформ не подтверждаются наличием кнопок. Ссылки на магазины приложений не добавлены. Production-деплой, слияние в `main`, смена домена и изменение исходного FriendSheep не выполнялись.
