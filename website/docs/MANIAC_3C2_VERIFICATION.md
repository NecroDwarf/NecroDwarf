## Голосование

Проверены MapVotingManager, VoteMapCommand, MapVotingScreen, VotingTicketItem и GameSettings.
Раздел «Как выбирается карта» находится в каталоге; он не является голосованием на сайте.

Один текущий голос на UUID; новый выбор заменяет прежний. При равенстве выбирается
случайный лидер. При отсутствии голосов — случайная зарегистрированная карта.
На секундной проверке, если число голосов равно текущему числу игроков сервера и
осталось больше 5 с, отсчёт сокращается до 5 с. Это условие не подменено утверждением,
что любой матч всегда имеет пятисекундный выбор.

Результат отправляется для анимации, затем сервер фиксирует scoreboard через
160 тиков (около 8 с). Клиентский RESULT_DISPLAY_DURATION=200 тиков — другой
параметр отображения; различие отмечено в сворачиваемых источниках.
Команда организатора принимает 10–300 с, по умолчанию 60 с. При выбранной в
GameSettings конкретной карте VoteMapCommand обходит голосование; неверный
numeric ID вызывает ошибку, а не фиктивный результат.

Использованы только оригинальные меню-превью `textures/gui/maps/mansion.png`,
`pizzeria.png`, `fort.png`. Они обозначены как игровые превью, а не планы уровней.

обрезки и растягивания. Генерированных игровых изображений нет.

## Архитектура и навигация

Общий EntityKind расширен настоящим типом `map`. Стабильные ID — `map:mansion`,
`map:pizzeria`, `map:fort`. `data/maps.ts` задаёт TypeScript-контракт и использует
краткий сгенерированный каталог; маршруты/публикация используют лёгкую проекцию
тех же исходных записей. Подробные статьи не дублируются в общем реестре.

Существующая SSG/routePage сохранена: полный HTML готов до гидратации, переходы
работают без перезагрузки. Все три статьи доступны через главный раздел и WikiLayout.
Связи механик выводятся из `relatedIds`, поэтому с двери/люков/вентиляции можно
перейти к Особняку/Пиццерии. Искусственных привязок ко всем персонажам нет.

В `fort-map` хроники 1.1 добавлен отдельный EntityLink на Форт. Ни текст JSON
хроники, ни её исторические значения не переписаны. Статья Форта ведёт обратно.
Для этих новых переходов добавлена локальная обработка якорей; основной App,
роутер и система загрузки страниц не менялись.
