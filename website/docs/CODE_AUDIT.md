## Что в структуре оставлено намеренно

- `app/shared` — общесайтовые компоненты, типы, стили и утилиты;
  `app/projects/<project>` — материалы и интерфейс конкретного проекта.
- Общие страницы получают проекты и выпуски из реестра. Код Wiki не добавлен
  в начальную загрузку приложения.
- Отдельные файлы статей и их тонкие страницы-обёртки сохранены: они обеспечивают
  загрузку только своей статьи и иллюстраций. Объединять их в большой eager-реестр
  ради сокращения числа файлов нельзя.
- Исторические снимки характеристик и текущие данные не объединены:
  одинаковые значения в них представляют разные проверенные состояния игры.
- Карточки персонажей, предметов и карт сохраняют разные композиции.
  Общий компонент с большим числом флагов здесь усложнил бы поддержку.
- Старые концепции находятся вне публичного entry point и сохранены как архив.
  FriendSheep и NovellMaker используют существующий `ProjectIntro`.

## Оставшиеся задачи

1. **Поведение навигации:** состояние поиска/фильтров и позиция прокрутки
   не восстанавливаются после возврата из статьи. `App` прокручивает наверх
   при смене pathname. Для исправления нужно отдельно согласовать URL-параметры,
   переходы назад/вперёд и работу якорей. В этом рефакторинге поведение сохранено.
2. **Стили Wiki:** `Wiki.module.css` содержит более тысячи строк и объединяет
   несколько экранов. Выделение стилей каталогов, статьи и главной следует делать
   с визуальной проверкой desktop/mobile. Текущие CSS-селекторы сохранены.
3. **Инструменты проверок:** browser-скрипты повторяют запуск Edge, создание
   статического сервера и сбор ошибок. Есть смысл выделить общий жизненный цикл
   при следующей доработке browser-проверок; в этот этап они не переписывались.
4. **Документация:** README содержит исторические описания будущих этапов,
   часть которых уже реализована. Отчёты этапов остаются историей; их не следует
   использовать как единственный источник текущего состояния.

Публикация, домен, баланс и новые функции проектов не менялись. Браузерные
интерактивные сценарии и полный визуальный аудит в этом этапе не запускались.
