## Как редактировать

- `wiki/data/gameplay-facts.ts` — общие актуальные характеристики шести
  связанных систем: Балтика, очки, Футбольный фанат, чума, Орхидея, Росток.
- В коротких описаниях используются эти константы; в JSON статей доступны
  именованные вставки вида `{{glasses.reductionPercent}}`.
  Неизвестное имя вызывает ошибку сборки. Текст с такими вставками проходит
  через `formatGameText`; в готовом HTML фигурных вставок нет.
- `wiki/data/item-access.ts` — доступность предметов по командам. Связь
  с конкретным персонажем остаётся отдельным фильтром. Неизвестная команда
  не назначается по догадке.
- `wiki/data/effect-connections.ts` — один список связей в обоих направлениях.
- `wiki/ui/WikiText.tsx` — общие правила ссылок на упомянутые сущности;
  оформление — общий `EntityLink`.
- `shared/lib/use-url-filter.ts` — URL-параметры каталогов. Правки поиска
  заменяют текущую запись истории, поэтому каждое нажатие клавиши не создаёт
  отдельный шаг «Назад». При гидратации сначала совпадает полный статический
  каталог, затем применяются параметры ссылки.
- `shared/lib/use-page-scroll.ts` — позиция по ключу истории, якоря и фокус
  при смене страницы. Хранится до 100 позиций в памяти текущей вкладки.
- `wiki/pages/styles/{shell,catalog,article,responsive}.css` — части прежнего
  CSS Module. Импорты инлайнятся до обработки CSS Modules.

Дополнительно: ID предметов и механик теперь выводятся из slug без повторения
строк, с сохранением прежних URL. Сводки персонажей выделены из общего реестра:
главная Maniac больше не загружает данные предметов, перков и механик ради трёх
коротких описаний. В проверяемом графе JS страницы Maniac стало 365 320 байт
вместо 542 907 при промежуточной сборке до этого выделения. Исторические
бюджеты загрузки в тестах не ослаблялись.

## Ограничения и отдельное наблюдение

Это исправление перечисленных проблем, а не полная повторная верификация
всего баланса игры. Неизвестные способы получения и правила внешнего датапака
не заменены предположениями. Физическое сенсорное устройство не использовалось.

При проверке dev-сервера обнаружено отдельное предупреждение гидратации:
`src/main.tsx` использует `root.hasChildNodes()`, а в dev-шаблоне внутри root
есть комментарий `<!--app-html-->`. Комментарий ошибочно принимается за
серверную разметку. Готовая SSG-сборка проверена отдельно и этой ошибки не дала.
Это новая находка вне исходных девяти пунктов: предлагается отдельное точечное
исправление выбора createRoot/hydrateRoot, без изменения схемы SSG.

Production, домен и игровой репозиторий не менялись.

## Единые иконки характеристик

`InlineStat` объединяет SVG, цвет, доступную подпись и подсказку; его используют
эффекты и таблицы параметров. `StatText` заменяет единицы рядом с числовыми
значениями в описаниях карточек, статьях и хрониках. Поддерживаются HP, мана,
урон, скорость, взлом, расстояние, время, уровень, броня, рассудок и прочность.
Обычные упоминания механик и номера версий остаются текстом. На обзорных
страницах без числовых характеристик этот обработчик не загружается.

Исходные слова единиц сохранены скрытым текстом для копирования и проверки
исторических материалов; экранный диктор получает подпись иконки. Внутри
карточек-ссылок нет дополнительных остановок Tab. В статьях подсказки доступны
при фокусе с клавиатуры. Числа, условия и баланс не изменены.

Добавлен `npm run check:stats`: примеры характеристик, защита от ложных замен,
сохранность 1815 строк статей, доступные подписи и SSG-карточка «Прыжок зверя».
Проверка хроник по-прежнему сравнивает точные хеши исходного текста, учитывая
вложенную разметку иконок. Лимиты размера JS не изменены.
