# Maniac 2B — полноценные хроники

Дата: 25.10.2026. Рабочая ветка `test`. Production-деплой, push и слияние в main
не выполнялись. В начале уже были незакоммиченные изменения 2B-0.1, включая
EntityIcon и открытый рендер зажигалки; они сохранены и использованы.

## Готовые страницы и архитектура

| URL | Содержание |
| --- | --- |
| `/projects/maniac/changelog` | Статичные тематические карточки трёх выпусков |
| `/projects/maniac/changelog/1.0` | Maniac Reforge, полный текст 8 разделов |
| `/projects/maniac/changelog/1.1` | Кошмарный додеп, полный текст 7 разделов |
| `/projects/maniac/changelog/1.2` | Flower Cleaning, полный текст 9 разделов |

`/changelog` остаётся общей лентой NecroDwarf; ссылки выпусков ведут на новые
внутренние страницы. На странице Maniac большая карточка и мини-карточки ведут
к своему выпуску, «Все обновления» — к истории Maniac. Старые семь URL сохранены.

Метаданные названий, версий, порядка и обложек остаются только в
`changelogs/registry.ts`. Необязательный `Release.href` отделяет внутреннюю
публикацию от внешнего `source`; общие компоненты сохраняют прежнее поведение
для проектов без собственной хроники. Неизвестные даты не добавлены.

Новые компоненты внутри модуля Maniac: ChroniclePage, ChronicleText,
ManiacChangelogPage и ReleaseDecor. Общий шаблон и CSS Modules заменяют три копии
JSX. Для длинных авторских материалов выбран типизированный TSX renderer с
локальными JSON-деревьями в `changelogs/content/`, без нового MDX-компилятора.
Это статические текстовые данные с ограниченным набором тегов, не старый HTML
документ и не вставка через dangerouslySetInnerHTML. Удалены старые layout,
шрифты, inline styles, JavaScript и обработчики. Сохранены смысловые элементы,
заголовки карточек, списки, строки баланса, предупреждения и авторские примечания.
Старая некорректная вложенность списков исправлена без изменения слов.

Каждая страница имеет первый экран, оригинальное введение и показатели, оглавление,
полный текст, источник, переходы между версиями, возврат к Maniac и якорь в начало.
Оглавление sticky на desktop, обычное развёрнутое на mobile. Все важные сведения
присутствуют в SSG HTML и доступны без JavaScript. На мобильных карточки становятся
более плотными разделителями с текстом, вместо больших рамок вокруг каждого блока.

## Полнота и источники

Удалённая main проверена через GitHub connector: commit
`8692f66dc76582144be85d553d43a41f189b64e7`, тот же, что у фундамента.
Исходники мода не изменялись. Использованы три оригинальные HTML-хроники,
`docs/css/changelog.css`, `docs/css/flower-cleaning.css`, `docs/css/style.css`
и оригинальный `docs/images/flower-sprig.svg`.

Полная таблица соответствия: [MANIAC_CHRONICLES_SECTIONS.md](MANIAC_CHRONICLES_SECTIONS.md).
Машинная версия с SHA-256 исходных файлов и текстов каждого раздела:
[maniac-chronicles-correspondence.json](maniac-chronicles-correspondence.json).

Сохранены 24 раздела, примерно 22 330 знаков основного авторского текста после
нормализации пробелов, плюс оригинальные вводные строки и показатели.
Старые общесайтовые header/nav/footer и декоративные разделители в эту оценку
не входят. Внутренние ссылки старых HTML направлены на соответствующие новые URL;
`#top` адаптирован к `#chronicle-top`.

Новая проверка сравнивает текст каждого раздела сразу в двух местах:
в данных и в построенном HTML. Только пробельные символы исключаются из
контрольной суммы; буквы, знаки, числа и порядок исходных фрагментов сохраняются.
Маркер data-original-text позволяет отличить авторский текст от добавленных
подписей snapshot и элементов навигации. Иконки и метаданные не заменяют исходные
параграфы. Смысловые сокращения и исправления баланса не выполнялись.

Для трёх персонажей, Концентрированного кошмара и зажигалки добавлены отдельные
снимки `release:1.1` по оригинальной хронике. Существующие source-снимки и
`release:1.2` Незабудки не перезаписаны. Публичный renderer всегда передаёт
явный release snapshot. Пример: 60-секундная перезарядка Незабудки из текущего
кода не появляется в её записи 1.2, где такого значения нет.

EntityCard получил необязательные title/editorial/showStats: полный исторический
текст передаётся отдельно, вместо повторного отображения современной краткой
справки. ReleaseEntityChange поддерживает такую запись; EntityIcon и EntityLink
переиспользуются. При публикации Wiki-ссылки появятся через общий реестр,
сейчас фиктивных адресов нет. 3D-движок и GLB на страницах хроник не используются.

## Темы и анимации

| Выпуск | Оформление | Движение |
| --- | --- | --- |
| Reforge | Сталь, бронза, янтарные акценты, прежняя кузнечная обложка | 8 поднимающихся искр с разными отклонениями и дыхание янтарного свечения за содержимым всей хроники, появление заголовка/секций, hover |
| Кошмарный додеп | Тёмно-фиолетовые поверхности, холодные акценты, прежняя обложка | Два боковых слоя дымки и редкие глаза из темноты, спокойное появление заголовка/секций |
| Flower Cleaning | Тёмно-зелёные поверхности, розовый/кремовый, цветочная обложка и оригинальные ветви по краям | 12 лепестков с разными траекториями/задержками, движение по всей длине страницы, hover |

Лепестки адаптируют идею оригинального flower-cleaning.css: фазы полёта,
вращение, отрицательные задержки, разные длительности, умеренная прозрачность.
Кузнечные искры и кошмарная дымка — новые эффекты для этих тем; им не приписывается
наличие в старом CSS. Все темы используют существующие Geologica + Rubik,
BrandLogo, общую шапку и футер. Новые изображения персонажей не генерировались.

На mobile остаются 4 искры, 1 слой дымки или 6 лепестков; глаза скрыты.
При reduced motion движение и transitions отключены, а закрытые глаза полностью
невидимы. Основной текст никогда не имеет opacity 0; эффекты не используются как
условие показа содержимого. У декора pointer-events:none, user-select:none и
фиксированное число элементов. Нет Canvas, WebGL, обработчиков и JS-таймеров.
React удаляет декор при смене маршрута. Страница списка остаётся статичной.

Окончательное уточнение команды 26.10.2026: это дальний фон, который находится
ниже обложек и содержимого. ReleaseDecor имеет z-index:-1 внутри изолированной
страницы. Первый экран имеет собственную непрозрачную основу и контекст наложения,
поэтому дым, глаза, искры и лепестки не просвечивают через его изображение.
При прокрутке фон виден в свободных боковых полях за основным содержимым.

Общая боковая маска плавно затухает на широкой полосе (до 420 px), сохраняя центр
с текстом свободным от декора. Ширина полей связана с шириной контейнера и его
адаптивными отступами, плюс 12 px безопасного зазора. Свечение меняет только opacity,
чтобы его прямоугольные границы не сжимались внутрь viewport.

В Nightmare оставлены только дым и NightmareEyes — по одному небольшому глазу
с каждой стороны. Циклы 37 и 49 секунд с разными задержками; большую часть времени
глаза скрыты, затем медленно открываются и исчезают. Постоянной линии закрытого века
нет. Лозы, щупальца и дополнительная пульсирующая аура удалены по решению команды.
Это декоративный SVG, не новая игровая сущность. Градиенты имеют уникальные ID,
орнамент aria-hidden и не получает клики/фокус. На мобильных глаза не отображаются.

Проверены боковые поля, фазы полного открытия/закрытия, reduced motion, отсутствие
переполнения и ошибок JS. Контроль обложки: кадры с декором и без декора сравниваются
отдельно от основного текста. Актуальные результаты — `rear-background-results.json`,
примеры — `rear-hero-*.png` и `rear-body-*.png`. Прежние скриншоты с лозами и щупальцами
относятся к отменённому варианту оформления.

## Вопросы для команды и ограничения

- Даты выпусков по-прежнему не подтверждены; они не придуманы для SEO или списка.
- Хроника 1.1 говорит о трёх первых лабиринтах, актуальный NightmareConfig — о двух.
  Исторический текст сохранён. Уточнение нужно для будущей актуальной Wiki.
- В хронике 1.2 лужи краски описаны для наступившего выжившего; современная
  локализация упоминает также маньяка. Это расхождение сохранено, а не исправлено
  задним числом по современным данным.
- Показатели файлов/строк кода — авторские показатели Reforge из оригинала;
  независимый подсчёт всего исходного релиза не проводился.
- Точное соответствие нынешней main мода всем характеристикам публичного архива
  не утверждается. Исторические числа взяты из конкретных хроник.
- Поиск, полноценные статьи Wiki, остальные модели и карты остаются вне этапа.
