## Проверенные ссылки и файл

- [Google Drive, страница файла](https://drive.google.com/file/d/1Pe_mgHtMvoVIn5-FwG5Nj_sG0xuDvY6D/view)
- [Google Drive, непосредственная загрузка](https://drive.usercontent.google.com/download?id=1Pe_mgHtMvoVIn5-FwG5Nj_sG0xuDvY6D&export=download&confirm=t)
- [Яндекс Диск, резервное зеркало](https://disk.yandex.ru/d/z7mqmWDD3k9OTg)

Google download возвращает HTTP 200, `application/octet-stream`, заголовок
`Content-Disposition: attachment; filename="maniac 1.2.zip"`, размер
220 494 053 байта. Начальные байты `50 4b 03 04` — ZIP, не HTML. Полный файл
скачан стандартным HTTP-клиентом без входа и промежуточного подтверждения.
CRC основного ZIP, вложенных mods.zip и world.zip проверены — ошибок нет.

```text
SHA-256: d672cec7762c37cb4f3bd5b0c6bad911e267ca8130000b7b37bfdb77345777fb
```

Эта сумма совпадает с SHA-256 публичных метаданных Яндекс Диска; размер и имя также
совпадают. Range-запрос по ссылке загрузки, полученной из публичного API Яндекса,
возвращает HTTP 206, application/zip и ZIP-байты. Полный второй файл не скачивался.
В интерфейсе используется стабильная публичная страница Яндекса, а не истекающий
адрес из API. На зеркало пользователь переходит без Minecraft Inside.

Версия 1.2 подтверждена не только именем файла: внутри maniacrev JAR найдены классы,
ресурсы и локализация цветочных систем из хроник Flower Cleaning — Незабудка,
Розовая Орхидея, СберРосток, Следствие ведут цветы, Букет на тот свет,
Диспетчер бутонов. Техническое имя JAR `maniacrev-1.0-SNAPSHOT.jar` не приравнивается
к публичному номеру выпуска. Моды и игра не запускались.

## Браузер

Установленный Microsoft Edge через Playwright; готовая SSG-сборка localhost:4173.
На 320, 390, 768, 1440 px: нет горизонтальной прокрутки, обрезанного текста и ошибок
JavaScript. Есть по две основные ссылки и по два зеркала (Hero и установка).
Скриншоты Hero и блока установки просмотрены на desktop/mobile.

В режимах 390 и 1440 px выполнены **реальные клики без подмены облачных ответов**:
Google сразу создаёт браузерное событие download с именем `maniac 1.2.zip` и
проверенным URL. HTML-страница или дополнительное подтверждение не появлялись;
исходная страница Maniac сохраняется. Повторные браузерные загрузки отменены
после фиксации события, поскольку полный архив уже скачан и проверен HTTP-клиентом.
Клик зеркала открывает новую вкладку с заголовком `maniac 1.2.zip — Яндекс Диск`.
Перенаправление ведёт на disk.360.yandex.ru с тем же публичным ключом.
Видимый фокус проверен клавишами Tab/Shift+Tab.

## Ограничения и артефакты

Скачивание ZIP напрямую через Google удалось в текущей проверке, включая браузер.
Облачный сервис может позже ввести лимит или дополнительное подтверждение;
для этого сохранены подсказка и проверенное зеркало. Реальное мобильное устройство
и другие браузерные движки не проверялись — использованы режимы viewport Edge.

Архив и verification.json находятся **вне репозитория сайта**, в папке артефактов
чата `maniac-download-verification`. В Git, public и build/client архива нет.
Там же сохранены browser-results.json и скриншоты hero-*/download-*.
Подробная установка теперь учитывает два вложенных ZIP и необходимость поместить
level.dat в saves/Maniac. Полные хроники, Wiki и публикация остались за рамками.
