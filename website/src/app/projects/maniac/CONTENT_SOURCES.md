## Скачивание: подтверждённое и спорное

ТЗ называет 1.2 текущей публичной версией. Хроники подтверждают выпуск Flower
Cleaning 1.2, поэтому он выделен как «Последний опубликованный выпуск».
Однако доступная веб-представлению страница Minecraft Inside описывает актуальную
версию как 1.1 и содержит ссылки с метками 1.0/1.1. Это расхождение не скрывается:
публичный блок скачивания предупреждает, что версия архива пока не подтверждена.
Кнопки ведут на саму страницу Minecraft Inside, а не на файл с обещанием версии 1.2.

Проверены существующие публичные ссылки:

| Ресурс                                                                                 | Результат                                                                                               |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [Google Drive](https://drive.google.com/file/d/1hqYkDo3Ji_M0Za4vmbr8cwS_r-RK3DHA/view) | HTTP 200, страница файла `Maniac.zip`; один и тот же ID указан на Minecraft Inside для 1.0 и 1.1        |
| [Яндекс Диск, метка 1.0](https://disk.360.yandex.ru/d/-F6Sg6CnjxaNlw)                  | HTTP 200, страница `Maniac.zip`                                                                         |
| [Яндекс Диск, метка 1.1](https://disk.yandex.ru/d/vwQr8dYkxwlgig)                      | HTTP 200; публичный API подтверждает ZIP размером 223 027 952 байта; HEAD по ссылке загрузки — HTTP 200 |

Архивы не запускались и их содержимое не исследовано; принадлежность архива к 1.2
не установлена. Не заявлены ни совпадение зеркал, ни проверка целостности или
полного скачивания. Прямые ссылки в интерфейс не добавлены.
Прямой HTTP-запрос к Minecraft Inside из shell получил 403, веб-инструмент прочитал
страницу. Поэтому доступность источника может зависеть от клиента/антибот-защиты.
Даты загрузки стороннего сайта не использованы как даты выпуска.

Для подтверждения прямой загрузки 1.2 нужны проверенный архив, его версия и
согласованный URL. До этого безопасный переход на страницу источника соответствует
разрешённому в ТЗ варианту. Точные Forge, зависимости и параметры многопользовательского
запуска из текущего кода не приравниваются к требованиям скачиваемой сборки.

## Изображения

Hero использует прежний `ManiacArt`, явно подписанный художественной иллюстрацией.
Существующие фоновые изображения релизов — тематическое оформление, не игровые
скриншоты. Новых изображений персонажей и вымышленных кадров нет.

Подтверждённых игровых скриншотов с разрешением на использование не найдено.
`meta.gallery` отсутствует, поэтому и галерея, и её пункт навигации скрыты.
Когда материалы будут предоставлены, добавьте их по `PROJECT_CONTENT.md` в
папку проекта и укажите `meta.gallery`: существующий `ProjectGallery` подключён.
