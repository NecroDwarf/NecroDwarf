## Скачивание Flower Cleaning 1.2 — проверено 24.10.2026

Основная кнопка в Hero и блоке установки ведёт непосредственно на
[Google Drive download](https://drive.usercontent.google.com/download?id=1Pe_mgHtMvoVIn5-FwG5Nj_sG0xuDvY6D&export=download&confirm=t).
Рядом доступно [зеркало Яндекс Диска](https://disk.yandex.ru/d/z7mqmWDD3k9OTg).
Это постоянные публичные URL; временная подписанная ссылка Яндекса используется
только при проверке и в код сайта не сохраняется.

### Ответы серверов

- [Страница Google Drive](https://drive.google.com/file/d/1Pe_mgHtMvoVIn5-FwG5Nj_sG0xuDvY6D/view):
  HTTP 200, название `maniac 1.2.zip`. Само по себе это не доказательство версии.
- URL непосредственной загрузки: HTTP 200, `Content-Type: application/octet-stream`,
  `Content-Disposition: attachment; filename="maniac 1.2.zip"`,
  `Content-Length: 220494053`. Первые байты — `50 4b 03 04` (ZIP), не HTML.
  Выполнено полное скачивание без авторизации и дополнительной HTML-страницы.
- Яндекс: публичная страница `maniac 1.2.zip`, HTTP 200 (перенаправление на
  `disk.360.yandex.ru` сохраняет тот же публичный ключ). Публичный API сообщает
  `application/zip`, размер 220 494 053 байта и SHA-256, совпадающий со скачанным
  Google-файлом. Range-запрос по полученной от API ссылке возвращает HTTP 206,
  `application/zip` и ZIP-сигнатуру.

### Проверка содержимого

Архив Google скачан полностью **вне репозитория сайта**, в локальные артефакты
чата. Проверены размер, SHA-256, центральный каталог и CRC всех записей основного
ZIP, а также вложенных `mods.zip` и `world.zip`. Ошибок CRC нет.

```text
Файл: maniac 1.2.zip
Размер: 220494053 байта
SHA-256: d672cec7762c37cb4f3bd5b0c6bad911e267ca8130000b7b37bfdb77345777fb
```

Верхний уровень содержит ровно `mods.zip` и `world.zip`. В `mods.zip` находятся
моды, включая `maniacrev-1.0-SNAPSHOT.jar`. В этом JAR обнаружены классы и ресурсы
цветочных механик, описанных в хрониках 1.2: `ForgetMeNotPerk`, `PinkOrchidPerk`,
`FlowersLeadInvestigationPerk`, `BouquetToTheOtherSidePerk`, `RealityAnchorPerk`,
цветочные следы и краска. Русская локализация подтверждает «Незабудку», «Розовую
Орхидею», «СберРосток», «Следствие ведут цветы», «Букет на тот свет» и
«Диспетчер бутонов».

Имя сборки 1.2, предоставленные командой ссылки и фактические механики Flower
Cleaning позволяют подтвердить содержимое сборки 1.2, а не только доступность
страницы. Имя JAR `1.0-SNAPSHOT` — техническая версия мода; оно не использовано
как номер публичного релиза. Это также не историческая пометка «4.0».
Совпадение полного Google SHA-256 с SHA-256 Яндекса подтверждает одинаковое
содержимое двух зеркал на момент проверки; второй архив целиком не скачивался.
Игра и моды не запускались, игровой баланс этой проверкой не подтверждается.

В `world.zip` файл `level.dat` лежит в корне: содержимое нужно распаковать в
отдельную папку внутри `saves`, например `saves/Maniac`. Эта конкретная структура
учтена в инструкции. Minecraft 1.20.1 и Forge также подтверждаются содержимым
архива и метаданными зависимостей JAR; точная установка Forge не изменилась.

### Поведение и ограничения

Предупреждение о неподтверждённой версии удалено. Переход на Minecraft Inside и
старые ссылки с ID `1hqYkDo3Ji_M0Za4vmbr8cwS_r-RK3DHA`, `-F6Sg6CnjxaNlw`,
`vwQr8dYkxwlgig` больше не используются для загрузки: результаты их проверки
относились к предыдущему состоянию этапа 2A.

Внешние ссылки сохраняют `target="_blank"` и `rel="noopener noreferrer"` через
общий ContentLink. Не добавлен атрибут `download`, который не заставляет
сторонний сервер выдавать ZIP: непосредственную загрузку обеспечивает проверенный
HTTP-ответ Google с `Content-Disposition: attachment`.
Если облачный сервис позднее потребует подтверждение или введёт лимит,
пользователь видит короткую подсказку и может перейти на резервное зеркало.
Подтверждение в текущей HTTP-проверке не понадобилось.

Архив не входит в Git, `public` или build/client. Нет собственного сервера,
прокси, Workers, API-ключей и запросов к облачным API во время работы сайта.
Перед будущей заменой ссылки повторите проверку ZIP-байтов, размера, SHA-256 и
содержимого; не считайте HTTP 200, имя файла или расширение достаточными.
Облачные проверки не запускаются автоматически в CI: существующий check проверяет
постоянные URL, подписи кнопок, внешние атрибуты и отсутствие старого предупреждения.

## Изображения

Hero использует прежний `ManiacArt`, явно подписанный художественной иллюстрацией.
Существующие фоновые изображения релизов — тематическое оформление, не игровые
скриншоты. Новых изображений персонажей и вымышленных кадров нет.

Подтверждённых игровых скриншотов с разрешением на использование не найдено.
`meta.gallery` отсутствует, поэтому и галерея, и её пункт навигации скрыты.
Когда материалы будут предоставлены, добавьте их по `PROJECT_CONTENT.md` в
папку проекта и укажите `meta.gallery`: существующий `ProjectGallery` подключён.
