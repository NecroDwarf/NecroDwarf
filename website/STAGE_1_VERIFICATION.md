# Проверка этапов 0–1

Дата: 24 октября 2026. Локальная среда Windows, Node 22.13.0, npm 10.9.2.

## Результаты

- `npm run typecheck` — успешно (входит также в build).
- `npm run build` — успешно: 7 наполненных HTML-страниц и `404.html`, клиентские CSS/JS, брендовые PNG, `robots.txt`, `_redirects` в `build/client`.
- `npm run check` — успешно: прямые HTTP-запросы семи URL, один h1, title/description, отсутствие старых проектов, проверка внутренних ссылок и четырёх ресурсов, якорей, завершающего `/`, неизвестного URL и будущих Wiki/подробных хроник (HTTP 404).
- Проверена отдельная сборка с `SITE_URL=https://example.invalid`: правильные canonical и sitemap из семи страниц. Это зарезервированный тестовый origin. Итоговая сборка повторно выполнена **без** SITE_URL: noindex, sitemap отсутствует, фиктивного домена нет.
- `npm run format:check` — успешно.
- Установка зависимостей npm сообщает 0 vulnerabilities. Отдельный CI в GitHub ещё не запускался; workflow подготовлен.
- В сборке остаётся предупреждение Vite об игнорировании директивы `use client` внутри React Router. Ошибок сборки и ошибок гидратации в просмотренных страницах нет.

В консоли просмотренных основных страниц нет ошибок/предупреждений. CSS содержит видимые фокусы и reduced-motion; отдельная системная эмуляция reduced-motion и проверка экранным диктором не проводились. Другие браузерные движки не проверялись.
