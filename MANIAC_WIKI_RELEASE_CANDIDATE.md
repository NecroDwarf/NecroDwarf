# Maniac Wiki — Release Candidate

Проверка: **3 ноября 2026**, Windows, Node.js 22.13.0, Playwright 1.64.1 / Chromium.
Ветка `test`, исходный коммит `c3950ae` (`Finish maniac wiki`), рабочее дерево
в начале было чистым. Игровой источник: `8692f66dc76582144be85d553d43a41f189b64e7`.

## Готовность

Локальная Wiki доведена до RC: dev/SSG-гидратация исправлена, общий поиск
реализован, прежние страницы и контент сохранены. Сборка содержит **191 публичный
маршрут + 404**: все 190 прежних адресов и `/projects/maniac/wiki/search`.

**Согласованная временная заглушка:** зеркало Яндекс Диска недоступно
(`404 DiskNotFoundError`). По просьбе владельца его кнопка временно ведёт на
[Rickroll](https://www.youtube.com/watch?v=dQw4w9WgXcQ); на странице указано,
что зеркало пока не работает. Реальный архив скачивается через Google Drive.
Настоящее зеркало будет возвращено после получения действующего адреса.

Production-деплой, изменения Cloudflare, DNS, домена, GitHub Pages, ветки `main`
и исходного репозитория игры не выполнялись.

## Общий поиск

- **204 сущности:** 15 персонажей, 44 перка, 12 способностей, 69 предметов,
  28 механик, 3 карты и 33 эффекта. Исключённый `weak_instant_health` не появляется.
- Индекс строится из существующих метаданных публикации. В нём только названия,
  ID, slug и ссылки; игровые числа, тексты статей, изображения и исторические
  снимки не импортируются.
- Модуль индекса загружается динамически на странице поиска или при первом
  непустом вводе в шапке. Начальная загрузка остальных страниц его не запрашивает.
  Изоляция подтверждена графом сборки и фактической сетью.
- Русский поиск игнорирует регистр, пробелы по краям и различия е/ё;
  несколько слов должны присутствовать в одной записи.
- Результаты сгруппированы по семи разделам. Есть состояния пустого запроса,
  отсутствия результатов и ошибки загрузки, перезагрузка после сбоя.
- Query сохраняется в URL без добавления записи истории на каждую букву.
  Проверены возврат из результата, Back/Forward и переход к эффекту по якорю.
- Есть подпись поля, `role="search"`, live-счётчик, обычные ссылки для Tab/Enter,
  очистка Escape с сохранением фокуса, touch-сценарий и четыре ширины экрана.
- Без JavaScript SSG показывает пояснение и ссылки на все семь разделов.

приближение, перетаскивание, сброс и fallback при отсутствии WebGL.
Декорации всех трёх хроник анимируются; `prefers-reduced-motion` останавливает
их анимации. Проверены доступные имена характеристик и отсутствие вложенных
Tab-элементов; полноценный аудит настоящим экранным диктором не проводился.

## SEO, прямые адреса и скачивание

- Локальная production-конфигурация с `SITE_URL=https://example.invalid`:
  `npm run build` и `node scripts/check-build.mjs` проверили canonical,
  Open Graph URL, sitemap 191 маршрута и отсутствие noindex у публичных страниц.
  Это тестовый origin, не домен публикации. Итоговая обычная сборка восстановлена:
  `noindex, nofollow`, `robots.txt: Disallow: /`, sitemap отсутствует.
- Все публичные HTML открываются напрямую; ссылки и межстраничные якоря
  действительны. Неизвестные URL возвращают HTTP 404 с отдельным содержимым.
  Существующие trailing-slash 301 сохранены; неподтверждённые редиректы не добавлены.
- DEV Preview и черновики не попадают в публичную сборку/список маршрутов/sitemap.
- Google Drive: Range-запрос **206**, `application/octet-stream`,
  `attachment; filename="maniac 1.2.zip"`, полный размер по заголовку **220494053 байта**.
  Клик на сайте вызывает событие скачивания с правильным именем; загрузка сразу
  отменена. Полный архив заново не скачивался и его текущий SHA-256 не измерялся.
- Яндекс Диск открывается в новой вкладке, но файл недоступен: в браузере
  «Ничего не найдено», публичный API — `404 DiskNotFoundError`. Обычный HTTP-клиент
  дополнительно столкнулся с CAPTCHA/403. После этой проверки владелец согласовал
  временный Rickroll вместо неработающего зеркала. Кнопка по-прежнему открывает
  новую вкладку с `noopener noreferrer`; настоящий архив остаётся в Google Drive.

## Что остаётся на публикацию

1. Когда зеркало Яндекс Диска восстановится, заменить `download.mirrorUrl`, вернуть
   описание доступного зеркала и обновить ожидаемый адрес в проверках. Пока
   используется согласованный Rickroll; основной Google Drive доступен.
2. После push/PR проверить фактический GitHub Actions, включая браузерный artifact.
3. На разрешённом Cloudflare preview проверить прямые вложенные URL, 404,
   trailing-slash 301, MIME/кэширование и отсутствие DEV Preview.
4. После отдельного разрешения на production задать настоящий `SITE_URL`, проверить
   canonical/OG/sitemap/robots на настоящем домене, HTTPS и перенаправления.
5. Только по явной команде публиковать production/менять домен или старый сайт.

Реальные телефон, Safari/Firefox/Edge, экранный диктор, Cloudflare и публичный домен
не проверялись. Отдельный переход длинного контента на MDX и новые продуктовые
материалы остаются вне этого RC. Большой технический рефакторинг для завершения
Wiki не требуется.

## Поиск в шапке

По отдельной просьбе владельца добавлена постоянная форма в шапку всех страниц
Wiki. На desktop поле находится рядом с MANIAC WIKI, ссылки разделов — ниже;
на телефоне поле занимает всю ширину. При вводе открываются живые подсказки
с категориями; Enter или «Найти» открывает все результаты, если вариант не выбран.
Форма передаёт запрос через `q` и сохраняет SPA.
Ввод в шапке не меняет поиск и фильтры текущего каталога. На странице результатов
поле показывает текущий запрос; отдельное поле под заголовком сохраняет мгновенную
фильтрацию. Без JavaScript форма работает как обычный GET-переход к SSG-странице
поиска с доступом ко всем разделам.

Первоначально форма открывала только страницу результатов; живые подсказки
добавлены 4 ноября, их проверка и размеры приведены ниже. Чтобы сохранить прежние
бюджеты без повышения лимитов, сокращены
только production-имена CSS Modules. Таблица имён общая для клиента и SSG,
с проверкой конфликтов областей; CSS-свойства и стили остальных страниц не менялись.
Проверки анимаций используют стабильные DOM-признаки вместо служебных CSS-имён.

## Живые подсказки — 4 ноября 2026

В шапке теперь используется тот же поиск, что на странице результатов. Выпадающий
список показывает до шести подходящих записей с названиями разделов. Точное
совпадение выше начала названия, затем идут совпадения по словам и техническим ID.
Например, три записи «Розовые очки» подписаны «Перки», «Предметы» и «Эффекты».

- Стрелки выбирают вариант, Enter открывает его; «Найти» и «Все результаты»
  открывают полную выдачу. Первый Escape закрывает список и сохраняет запрос,
  повторный очищает поле. Tab и нажатие вне формы закрывают список.
- Работают мышь и touch. На коротком экране список прокручивается в доступной
  высоте; выбранная строка остаётся видимой. Поле имеет семантику combobox,
  список — listbox, активный вариант связан через `aria-activedescendant`.
- При медленной загрузке используется последний введённый запрос, закрытый список
  не открывается сам. Есть состояния загрузки, ошибки и отсутствия совпадений;
  Enter при IME-композиции не выбирает вариант. Нативный GET без JS сохранён.
- UI подсказок и индекс загружаются после первого непустого ввода. Пустой фокус
  их не запрашивает; данные статей, хроники и 3D не входят в эту загрузку.

Начальная загрузка по графу импортов, относительно предыдущей версии формы:

| Область            | До, байт | После, байт | До gzip | После gzip |
| ------------------ | -------: | ----------: | ------: | ---------: |
| Основной entry     |   333227 |      333418 |  103522 |     103585 |
| Главная Wiki       |   358143 |      358248 |  112277 |     112303 |
| Каталог персонажей |   358665 |      358694 |  113541 |     113526 |

Число начальных чанков не выросло; прежние ограничения размеров не менялись.
На холодной главной Wiki ввод дополнительно запрашивает 8 587 байт JS
(3 797 байт при локальной оценке gzip): UI, индекс и метаданные эффектов.
Измерены реальные HTTP-ответы на ширинах 390 и 1440; ошибок страницы нет.
